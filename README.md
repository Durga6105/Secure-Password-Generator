# Secure-Password-Generator
# 🔐 Password Generator Web App

## 🚀 Overview

A simple and interactive **Password Generator** built using HTML, CSS, and JavaScript.
This application allows users to generate strong and secure passwords with customizable options like length, character types, and real-time strength analysis.

---

## ✨ Features

* 🔑 Generate random secure passwords
* 🎛️ Customize password length (8–20 characters)
* 🔠 Include:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Symbols
* 👁️ Toggle password visibility
* 📋 Copy password to clipboard
* 📊 Password strength indicator (Weak / Medium / Strong)
* 🌗 Light/Dark theme toggle
* 🔔 Toast notification for user actions
* 🎨 Modern UI with animated gradient background

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & animations
* **JavaScript (Vanilla JS)** – Logic & interactivity
